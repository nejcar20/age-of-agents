# Raids Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Scan each island's dependencies for known vulnerabilities on demand and show every finding as an attacker (pirate ships at sea, raiders in town) that you can inspect and send an agent to fix.

**Architecture:** A new Rust module `src-tauri/src/raids/` runs `osv-scanner` (preferred) or `npm audit` through a shared bounded-process helper. It normalises their JSON into one `RaidReport` per canonical island root, persists the reports in `~/.age-of-agents/raids.json`, and emits a `raid-report` event as each scan finishes. The frontend keeps pure logic in `src/raids.ts` (ship selection, smoke, raider grouping, defend prompt) and renders it in new components hooked into `Archipelago.tsx`, `TownView.tsx` and the island panel.

**Tech Stack:** Rust (Tauri 2, serde_json, std::process), React 19 + @react-three/fiber + three, vitest.

**Spec:** `docs/superpowers/specs/2026-10-30-raids-design.md`. Read it first. Its "Decisions settled after review" section is binding.

## Global Constraints

- Never show a root as safe unless it was fully checked. `Clean` requires zero findings **and** an empty `uncovered`.
- Each attacker is exactly one real finding. Nothing is decorative.
- At most **6** ships per island, highest severity first, plus a "+N" badge for the rest.
- Smoke appears iff the report is not stale and has ≥1 critical or ≥3 high findings.
- Scans run only when the user asks: no timers, no rescans on focus or save. `scout_all` runs at most **2** scans at a time.
- Nothing is sent to an agent without an explicit Send click. Defending goes through the existing `send_prompt` with `expectedRoot`.
- The app never installs scanners. It may only *suggest* `brew install osv-scanner`.
- Browser preview / townshot harness: scouting and sending are disabled, and raid data comes from fixtures.
- Executables are found on PATH, then in `~/.local/bin`, `/opt/homebrew/bin` and `/usr/local/bin`, because Finder-launched apps get a minimal PATH.
- Per-scan budget: **120 s** timeout, **16 MiB** stdout cap.
- Match the surrounding code style, including its comment density and its doc comments that explain *why*.

## Review Focus

1. **A scanner exits non-zero because it found vulnerabilities.** That is a successful scan, not "unscouted". `npm audit` exits 1 when it finds vulnerabilities. `osv-scanner` exits 1 when it finds them and 128 when it finds no packages. *Task 3 tests these.*
2. **A repo has `package-lock.json` plus `Cargo.lock` and only npm is available.** It must be "partly scouted", not Clean, with no flag. *Task 4 tests this.*
3. **The lockfile changes after a scan** (an agent upgraded a package, or the branch switched). The report must be marked stale: no flag, no smoke, ships desaturated. *Tasks 2 and 4 test this.*
4. **A scanner's JSON is truncated (cap hit), empty or garbage.** The root becomes Unscouted with a reason; nothing panics and nothing is half-parsed into findings. *Task 3 tests this.*
5. **The defending agent works in a worktree.** The composer must name the worktree and the main root, and `expectedRoot` must be the agent's root as `send_prompt` expects. *Task 9 tests this.*

**Interfaces:**
- Produces (all `Serialize, Deserialize, Clone, Debug, PartialEq`; serde `rename_all = "snake_case"` on enums, matching the TS types in Task 6):
  ```rust
  pub enum Severity { Critical, High, Moderate, Low, Unknown }   // Ord: Critical highest
  pub struct Finding { pub id: String, pub summary: String, pub severity: Severity,
      pub package: String, pub installed: Option<String>, pub fixed_in: Option<String>,
      pub lockfile: String /* repo-relative */, pub url: String }
  pub struct LockfilePrint { pub path: String /* repo-relative */, pub hash: String /* 16 hex chars */ }
  #[serde(tag = "kind", rename_all = "snake_case")]
  pub enum RaidStatus { Clean, Raided { findings: Vec<Finding> }, Unscouted { reason: String } }
  pub struct RaidReport { pub root: String, pub scanned_at: i64 /* unix secs */,
      pub scanner: Option<String> /* "osv-scanner" | "npm-audit" */,
      pub covered: Vec<String>, pub uncovered: Vec<String>,
      pub fingerprint: Vec<LockfilePrint>, pub status: RaidStatus,
      #[serde(default)] pub stale: bool /* computed on read, never trusted from disk */ }
  pub fn severity_from_label(label: &str) -> Severity        // case-insensitive: critical/high/moderate|medium/low
  pub fn severity_from_cvss(score: f64) -> Severity          // ≥9 Critical, ≥7 High, ≥4 Moderate, >0 Low, else Unknown
  pub fn dedup(findings: Vec<Finding>) -> Vec<Finding>        // key (id, package, lockfile); keep first; then sort by severity desc, then id
  pub fn decide_status(findings: Vec<Finding>, covered: &[String], uncovered: &[String]) -> RaidStatus
  ```
- `decide_status` rule (spec, Decision 3):
  - findings non-empty → `Raided` (deduped)
  - covered empty → `Unscouted { "no scanner could read this repository's lockfiles" }`, or `"no lockfile found"` if `uncovered` is also empty
  - uncovered non-empty → `Unscouted { "partly scouted: <comma-joined uncovered> not checked (install osv-scanner)" }`
  - otherwise → `Clean`

**Interfaces:**
- Consumes: `Finding`, `Severity`, `severity_from_label`, `severity_from_cvss` (Task 2).
- Produces:
  - `pub fn parse_npm_audit(json: &[u8], lockfile: &str) -> Result<Vec<Finding>, String>`
  - `pub fn parse_osv(json: &[u8], root: &Path) -> Result<(Vec<Finding>, Vec<String> /* covered lockfiles, repo-relative */), String>`
- Mapping:
  - **npm (`auditReportVersion` 2):**
    - Each object in `vulnerabilities.*.via` becomes one Finding. String entries are transitive references and are skipped.
    - `id` is the last path segment of `via.url` (the GHSA id), or `"npm-" + via.source` if there is no url.
    - `summary` = `via.title`.
    - `severity` = `severity_from_label(via.severity)`.
    - `package` = `via.name`.
    - `installed` = None, because npm audit doesn't report it.
    - `fixed_in` = `fixAvailable.version` when `fixAvailable` is an object whose `name == package`, otherwise None.
    - `url` = `via.url`.
    - `lockfile` = the argument.
    - A missing `auditReportVersion` or `vulnerabilities` is an Err.
  - **osv:**
    - For each `results[].packages[].vulnerabilities[]`:
      - `severity`: from `database_specific.severity` label if present. Otherwise, from the matching `groups[]` entry (the one whose `ids` contains the vuln id) as `max_severity`, parsed as f64, via `severity_from_cvss`. Otherwise Unknown.
      - `fixed_in`: the first `affected[].ranges[].events[].fixed`.
      - `installed`: `package.version`.
      - `url`: `https://osv.dev/vulnerability/<id>`.
      - `lockfile`: `results[].source.path` made relative to `root`.
    - Each `results[].source.path` (relative to `root`) is added to `covered`.
    - A missing `results` key is an Err. An empty `results` returns `Ok((vec![], vec![]))`.
- Exit-code interpretation lives in Task 5, but `parse_*` must accept any well-formed body regardless of exit status.

### Task 4: Lockfile discovery, coverage and fingerprints

**Files:**
- Create: `src-tauri/src/raids/lockfiles.rs`

**Interfaces:**
- Consumes: `LockfilePrint` (Task 2), `process::run_bounded` (Task 1).
- Produces:
  - `pub const LOCKFILE_NAMES: &[&str] = &["package-lock.json", "yarn.lock", "pnpm-lock.yaml", "Cargo.lock", "poetry.lock", "go.sum", "Gemfile.lock"];`
  - `pub fn discover_lockfiles(root: &Path) -> Result<Vec<String>, String>`: runs `git ls-files -co --exclude-standard -z` bounded, keeps paths whose file name is in `LOCKFILE_NAMES`, excludes any path with a `node_modules` component, and returns them sorted.
  - `pub fn npm_audit_coverage(lockfiles: &[String]) -> (Vec<String>, Vec<String>)` returns `(covered, uncovered)`. Only a **root-level** `package-lock.json` is covered; everything else is uncovered.
  - `pub fn fingerprint(root: &Path, lockfiles: &[String]) -> Vec<LockfilePrint>`: FNV-1a 64 over file bytes, written as 16 lowercase hex chars. An unreadable file gets the hash `"unreadable"`.
  - `pub fn is_stale(stored: &[LockfilePrint], current: &[LockfilePrint]) -> bool` returns true unless the two match exactly as path→hash sets.
  - `pub fn manifest_for_lockfile(lockfile: &str) -> String` maps to the sibling path: `package-lock.json`/`yarn.lock`/`pnpm-lock.yaml`→`package.json`, `Cargo.lock`→`Cargo.toml`, `poetry.lock`→`pyproject.toml`, `go.sum`→`go.mod`, `Gemfile.lock`→`Gemfile`. Any other path is returned unchanged. (The frontend mirrors this in Task 6.)

**Files:**

- Modify: `src-tauri/src/lib.rs` (register commands)
- Modify: `src-tauri/src/commands.rs` only if needed to share the "known island roots" gathering used by `get_archipelago`. Extract it into a small fn rather than copying it.

**Interfaces:**
- Consumes: everything from Tasks 1–4; `config::data_path`; `cache_io::{atomic_write, with_cache_lock}`; `build_archipelago` roots.
- Produces:
  - `pub struct Scanners { pub osv: Option<PathBuf>, pub npm: Option<PathBuf> }` and `pub fn detect_scanners() -> Scanners`
  - `pub fn scout_root(root: &Path, scanners: &Scanners, now: i64, run: &dyn Fn(Command) -> Result<BoundedOutput, String>) -> RaidReport`. The runner is injected so tests can fake it. The algorithm:
    1. Run `discover_lockfiles`. On Err, return `Unscouted { "could not list files: …" }`.
    2. If there are no lockfiles, return `decide_status(vec![], &[], &[])`, i.e. "no lockfile found".
    3. If osv is available, run `osv-scanner scan source --format json --recursive <root>` (check flags with `osv-scanner --help`; v1 is `--format json -r`).
       - Exit codes 0, 1 and 128: parse stdout. With 128 or empty `results`, `covered` is empty.
       - Anything else, an Err, or `truncated == true`: Unscouted with the stderr's first line, or "timed out", or "output too large".
       - Uncovered = discovered lockfiles not in covered.
    4. Else if npm is available and `npm_audit_coverage` covers something, run `npm audit --json --package-lock-only` with `current_dir(root)`. Exit 0 or 1: parse. Otherwise: Unscouted.
    5. Else: Unscouted with "no scanner installed (install osv-scanner)".
    6. Fill in `fingerprint(root, &all_discovered)`, `scanner` and `scanned_at`.
  - `pub fn load_reports() -> HashMap<String, RaidReport>` and `pub fn save_report(report: &RaidReport)`. The cache file is `data_path("raids.json")` and holds a JSON map keyed by root. `save_report` does load-modify-save inside `with_cache_lock` and writes with `atomic_write`. A missing or torn file loads as empty.
  - Tauri commands:
    - `#[tauri::command] pub async fn raid_scanners() -> ScannersView { osv: bool, npm: bool }`
    - `#[tauri::command] pub async fn raid_reports() -> Result<Vec<RaidReport>, String>`: loads the cache and recomputes `stale` per report via `discover_lockfiles` + `fingerprint` + `is_stale`. If the root no longer exists, stale is true. Runs in `spawn_blocking`.
    - `#[tauri::command] pub async fn scout_island(app: AppHandle, root: String) -> Result<RaidReport, String>`: scouts, saves, emits `"raid-report"` with the report, and returns it.
    - `#[tauri::command] pub async fn scout_all(app: AppHandle, state: State<AppState>) -> Result<usize, String>`:
      - gets the same root set `get_archipelago` uses (canonical `IslandView.root`)
      - spawns a background task that scouts at most 2 at a time; each finished report is saved and emitted as `"raid-report"`, and `"raid-scout-done"` is emitted at the end
      - returns the island count immediately
      - a second call while one is running returns `Err("already scouting")` (an `AtomicBool` in a static or `AppState`)
- The per-scan budget comes from Global Constraints.
